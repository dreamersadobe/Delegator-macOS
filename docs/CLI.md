# Обнаружение собственных CLI

В разделе приложений добавлен блок «Собственные CLI». Нажмите **Обнаружить CLI**, отфильтруйте найденные команды, выберите нужную и нажмите **Добавить выбранный CLI**. Также можно указать название и полный путь вручную. Поиск выполняется в фоне, перечисляет файлы в PATH и пользовательских каталогах команд, не запускает обнаруженные программы и не отправляет сетевые запросы.

На Windows учитываются `.exe`, `.com`, `.cmd`, `.bat`, `.ps1`, на macOS — исполняемые файлы и ссылки на них. Повторяющиеся команды сворачиваются по приоритету PATH. Результаты поиска могут включать обычные системные утилиты: Delegator не объявляет каждую найденную команду AI-агентом. Добавляются только выбранные пользователем записи.

Новый CLI сохраняется выключенным в `config.json → custom_clis`. Для подключения Delegator укажите полный путь к Markdown-файлу инструкций `.md` / `.mdc`, который этот CLI действительно читает; поддерживается `~/`. Без файла инструкций запись только отображает наличие команды. Само обнаружение не означает совместимость CLI с инструкциями Delegator.

Включение добавляет отдельный управляемый блок с идентификатором CLI. Выключение, пауза Delegator и удаление записи снимают только этот блок, сохраняя сторонний текст, BOM и переводы строк вне блока. Повреждённые либо дублирующиеся маркеры отклоняются без перезаписи файла. Файлы встроенных интеграций и файлы, уже выбранные для другого CLI, нельзя назначать повторно. Удалить запись можно кнопкой «Удалить»; если нужен другой файл, удалите запись и добавьте её заново.

При глобальном возобновлении восстанавливаются только ранее включённые записи. `--remove-hooks` удаляет также блоки пользовательских CLI. Существующие конфигурации получают пустой список; ключи API, выбор IDE и моделей не меняются.

## Ensemble и Antigravity

Добавлена встроенная строка **Ensemble**. Детектор учитывает `ensemble` в PATH, `%LOCALAPPDATA%/Programs/AIEnsemble/bin/ensemble.js`, `~/.local/share/ai-ensemble-cli/bin/ensemble.js` и `~/.local/bin/ensemble`. Оставшийся каталог истории или hook-файл не считается установленной программой. Сам Ensemble распространяется отдельно; его исходников в этом репозитории нет.

Ensemble сам вызывает официальные Codex и Antigravity CLI. Для его интеграции Delegator записывает обычный блок в `~/.ai-ensemble/AGENTS.md` и машинный маркер:

```html
<!-- AI_ENSEMBLE_RUNTIME {"schemaVersion":1,"runtimeEntry":"/absolute/path/to/runtime/ai-delegate"} -->
```

На Windows путь указывает на `ai-delegate.cmd`, на macOS — на штатный `ai-delegate` launcher. Установленный Ensemble использует этот маркер для консультации и проверки ответа; включение по умолчанию отключено. Antigravity дополнительно обнаруживается по командам `agy` / `antigravity` в PATH.

## Проверка

```sh
cargo fmt --all -- --check
cargo test --locked
```

Тесты используют временные каталоги: проверяют обнаружение без запуска файлов, дубликаты PATH, отсутствие executable, безопасное включение/выключение hook, сохранение текста, ошибки маркеров и совместимость конфигурации. Unix-тест также проверяет executable bit.
